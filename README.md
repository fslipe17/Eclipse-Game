# Eclipse Game
Jogo desenvolvido utilizando HTML, CSS e JavaScript, com foco na aplicação de conceitos de Programação Orientada a Objetos (POO).

# Sobre o Projeto
O Eclipse Game foi desenvolvido como um projeto para praticar desenvolvimento web e lógica de programação.
O jogo utiliza JavaScript para controlar a lógica, os personagens, movimentações e interações, enquanto HTML e CSS são responsáveis pela estrutura e apresentação visual.

Este projeto foi desenvolvido por fslipe17.
